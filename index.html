Политика конфиденциальности

1. Коротко

  • Мы не продаем персональные данные.
  • Доступ к данным Здоровья — только с разрешения пользователя, которое можно отозвать в настройках iOS.
  • Данные HealthKit используются только для функциональности приложения.

2. Какие данные можем собирать/хранить

  • Данные тренировок, введенные пользователем: упражнения, подходы, повторения, вес, длительность, заметки.
  • Технические данные устройства: модель устройства, версия iOS, версия приложения, журналы сбоев (если есть).
  • Опциональная обезличенная аналитика использования (если включена).

3. HealthKit / Apple Health

Приложение может читать/записывать связанные с фитнесом данные (например, тренировки, активную энергию, показатели тела) только если вы предоставили разрешение.

  • HealthKit-данные не используются для рекламы или брокерских операций с данными.
  • HealthKit-данные не передаются третьим лицам, кроме случаев, необходимых для работы приложения (как правило, таких передач нет).
  • По умолчанию данные HealthKit обрабатываются на устройстве.

4–11. Использование, передача, хранение и удаление

Данные используются для работы функций, стабильности и поддержки пользователей. Продажи данных нет; возможна ограниченная передача минимальных технических данных сервис-провайдерам (например, аналитика/краш-репорты), но не данных HealthKit. Если в приложении нет аккаунта, данные обычно хранятся на устройстве. Удаление данных: используйте функции приложения и/или запрос на support@igymx.app с темой «Удаление данных». Мы применяем разумные меры безопасности, но не можем гарантировать абсолютную защиту. Сервис не предназначен для детей до 13 лет. Для международных пользователей применяются общие правила обработки данных в рамках действующего законодательства. Изменения политики публикуются на этой странице.

FAQ

Нужен ли аккаунт для использования?

Обычно нет: основные функции доступны без создания аккаунта.

Как отключить доступ к Apple Health?

Откройте iOS: Настройки → Конфиденциальность и безопасность → Здоровье и измените разрешения для приложения.

Используются ли мои данные для рекламы?

Нет, данные HealthKit не используются для рекламы.

Можно ли пользоваться приложением без интернета?

Да, основные функции трекера работают офлайн.

Как удалить данные?

Используйте функцию удаления в приложении или отправьте запрос на support@igymx.app с темой «Удаление данных».

Почему данные не синхронизируются с Apple Health?

Проверьте разрешения HealthKit и убедитесь, что они выданы для нужных типов данных.

Как сообщить об ошибке?

Напишите в поддержку, приложите скриншоты, версию iOS и версию приложения.
